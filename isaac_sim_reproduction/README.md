## 与论文工作的关系

当前工作是 I2O-RL 在固定基座 Panda / Isaac Sim 上的迁移及依据论文描述的实现重建，未接入 VLP。采用分层动作量化、示范预训练及 IL/RL 联合训练；本版本使用可微 soft-argmax 动作分支、MSE 模仿项、margin 项和加权标量 TD 项。具体计算以 `aligned/paper_update.py` 为准。

仿真器、任务资产、相机、复位分布和部分成功判据与原工作不同；取锅盖采用程序化场景，抽屉使用替代资产，放书限制为 variation 0 单本书且未要求释放。因此这些成功率不构成与原论文的严格横向比较，也不代表完整复现、泛化或真实机器人验证。

## 环境与运行边界

服务器原项目根目录为 `/home/ubuntu/pingandog`，已验证环境为 Isaac Sim 6.2.0 与 PyTorch 2.11.0+cu128。代码交付保留服务器实际运行版本，包含绝对路径、历史时间截止条件和已有数据路径；它不是克隆后即可直接运行的独立安装包。

训练前需准备对应 Isaac Sim 环境、任务 USD 资产、专家示范及需要恢复的 checkpoint，并核对脚本中的根路径、GPU 配置和截止时间。`scripts/` 提供现有环境启动与准备脚本。历史通用启动器可能自动选择 GPU；如沿用本次实验约束，必须使用限定物理 GPU 2/3/4 的隔离流程，见 `results/RUN_CONTRACT.md`，不要直接照抄历史文档命令。

本次交付没有启动任何训练，也没有改变服务器正在使用的代码。数据集、模型权重、视频、运行环境和大型资产仍保存在服务器，不随源码提交。资产许可副本位于 `asset_licenses/`；保留现有第三方代码声明，不为其重新指定许可证。
